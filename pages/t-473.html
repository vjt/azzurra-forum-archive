La scelta di Microsoft di non includere Java nel browser IE6 sotto Windows XP, peraltro molto discutibile, obbliga gli utenti XP/IE6 allo scaricamento della la Java Virtual Machine direttamente dal sito Microsoft a seguito dell'installazione dell'OS.

L'indirizzo per lo scaricamento della JVM è http://www.microsoft.com/java/vm/dl_vm40.htm?FinishURL=%2Fdownloads%2Frelease%2Easp %3Freleaseid%3D36820%26redirect%3Dno.

Purtroppo allo stato attuale non ci sono altre soluzioni, l'applet di per sè funziona, certo è che se manca l'interprete Java dal lato utente questa non è visualizzabile.

Se il problema invece è relativo e ristretto alla sola java applet di AzzurraNet (i.e. vedi tutte le altre applet java su altri siti, ma non ti funziona EIRC) posso soltanto consigliare di visitare il sito http://java.azzurra.org e richiedere la generazione di nuovi tag HTML.
A seguito di alcuni aggiornamenti infatti sono stati modificati alcuni dettagli e talune Java Chat potrebbero non funzionare correttamente (vd. post http://www.azzurra.org/forum/viewtopic.php?topic=648&forum=12&0).

Per qualsiasi altra informazione invito te e chiunque altro avesse riscontrato problemi con le JavaCR/JavaEIRC a inviare una mail all'indirizzo java@azzurra.org indicando l'indirizzo dove si trova la chat "incriminata".
Provvederemo quanto prima a risolvere il problema.
