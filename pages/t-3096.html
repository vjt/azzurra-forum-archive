Ciao, lo stack ipv6 per windows 2000 lo trovi qua:

http://msdn.microsoft.com/downloads/sdks/platform/tpipv6.asp

penso che tu abbia già provveduto a scaricare il file perché leggo nel tuo post: "ma lo stack per il mio SP non l'ho trovato".
Infatti se provi ad installare questo aggiornamento dovresti ricevere un errore (service pack errato).

Per poterlo installare correttamente, basta seguire le istruzioni riportate nelle FAQ all'indirizzo:

http://msdn.microsoft.com/downloads/sdks/platform/tpipv6/faq.asp

Esattamente alla domanda:

How do I install the Technology Preview on Windows 2000 SP3?

Tuttavia, affinché funzioni con SP4 bisogna modifcare il punto 5 con il seguente:

---------------------------------------------------------------------------------
5. In the [Version] section of the Hotfix.inf file, change the line
****NTServicePackVersion=256 to NTServicePackVersion=1024,
and then save changes.
---------------------------------------------------------------------------------

In pratica devi inserire 1024 (= NUMEROSP * 256) a posto di 768. (tnx drittz)

Spero di essere stato chiaro (da notare l'orario)!
