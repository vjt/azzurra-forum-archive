Se usi il VC++ puoi usare _snprintf :

int _snprintf( char *buffer, size_t count, const char *format [, argument] ... );
Ad eg:

#include <stdio.h>

int main(int argc, char* argv[]) {

char sz[5];

if (_snprintf(sz, sizeof(sz), "Hello World!") < 0)
sz[sizeof(sz) - 1] = 0;

printf(sz);

return 0;
}
