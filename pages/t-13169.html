Abilitare le statistiche lato client
Come già annunciato da Giacomo, per le Altroviadi è stato messo a disposizione da Alex1 un server temporaneo di Unreal Tournament 2004.
Il server è stato configurato per loggare tutte le partite e generare le statistiche per ogni partita e quelle complessive (carriera di ogni giocatore, classifiche, ecc.)
Alcune statistiche di esempio sono disponibili su http://altroviadi.lamerandia.org/ (verranno cancellate subito dopo l'apertura delle Altroviadi).

Per far funzionare il tutto, però, non basta che sia configurato adeguatamente solo il server, ma dovete configurare (in maniera semplice ed indolore) anche il vostro client.

Facendo riferimento a questa immagine:
http://img81.imageshack.us/img81/664/utstatscfg4lx.th.png (http://img81.imageshack.us/my.php?image=utstatscfg4lx.png)

1) Assicuratevi che "track stats" sia abilitato
2) Inserite uno username ed una password univoci assicurandovi che nell'area ID / Messages non ci sia nessun messaggio di errore
3) Siete pronti :D

NB: se avete già configurato ut2004 per le global stats non è necessario nessun cambiamento (le stats comunque non verranno inviate al master server epic).

Good Luck & Have Fun!

File necessari

Per accedere al server è necessario (sì, necessario) portare la propria installazione di ut2004 alla versione 3369.
L'unico file necessario è la patch 3369 disponibile qui (http://www.beyondunreal.com/main/ut2004/ut2004essential.php).

Nel caso vogliate installare anche l'ECE (consigliato per chi volesse giocare anche su altri server, ma NON necessario per le altroviadi), assicuratevi di installare la versione 1.1 PRIMA della patch 3369.

Volendo, potreste anche scaricare UTComp 1.6a (http://ut2004.gameamp.com/ut2004/viewUtcomp), ma nel caso non fosse installato il vostro client provvederà a scaricarlo automaticamente dal server (o meglio, dal servizio di download redirection di unrealadmin.org) alla prima connessione.

Nel caso fossero necessari ulteriori file non disponibili su unrealadmin.org aggiorneremo questo post :)
