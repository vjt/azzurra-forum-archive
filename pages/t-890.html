I passi fondamentali per installare un forum (qualsiasi esso sia) sono questi:


verifica che il provider presso il quale hai intenzione di pubblicare il forum supporti i requisiti che quest'ultimo impone (normalmente nella documentazione trovi scritto che tipo di supporto richieda, se ASP o PHP, e quale tipo di database sia necessario)

installa e configura il database come spiegato nella documentazione del forum

[list:90598b4956]
phpBB 1.4.x richiede la creazione di un database mysql, la creazione di un nome utente e l'impostazione di una password e dei relativi permessi di accesso e, infine, l'inserimento manuale di un file .sql, contenente le definizioni delle tabelle.

phpBB 2.0.x richiede soltanto la creazione del database e l'impostazione di username, password e permessi.
La creazione delle tabelle viene effettuata in modo automatica dalla procedura di installazione.



configura le impostazioni base del forum


Nel caso di phpBB 1.4.x si tratta di editare il file config.php e di settare i valori corretti che rispecchiano la configurazione del tuo web server

Nel caso di phpBB 2.0.x anche queste opzioni vengono settate in modo automatico dalla procedura di installazione (ulteriori personalizzazioni sono poi gestite totalmente dal pannello amministrativo)


esegui, se presente, la procedura di installazione (solitamente si tratta di richiamare l'indirizzo http://tuo.web.server/phpBB/install.php, ma anche in questo caso è bene leggere la documentazione allegata)
[/list:o:90598b4956]

A questo punto dovresti avere una installazione di default del tuo forum, senza alcuna opzione aggiuntiva, ma perfettamente funzionale nelle sue caratteristiche di base.
