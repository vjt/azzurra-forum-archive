DCC e Fastweb
Modifico il post per risolvere un problema riscontrato dagli utilizzatori del server delta.azzurra.org quando tentano di inviare DCC agli abbonati di altri provider. Tale soluzione si applica anche agli users che continuano ad utilizzare gli altri server di Azzurra.

Dunque... come tutti gli abbonati Fastweb sapranno una delle limitazioni più fastidiose dovute all'architettura della rete Fastweb è costituita dall'utilizzo di un IP privato e di server NAT che rendono problematico l'utilizzo delle DCC.

Purtroppo non è possibile trovare una soluzione definitiva che funzioni in ogni caso, ma si può comunque dividere il problema a seconda dei casi e risolvere l'intoppo in modi diversi.

CASO 1: DCC da abbonati Fastweb ad altri ISP

In questo caso i passi da compiere (usando mIRC) sono i seguenti:
1) Andare alla sezione Connect-&gt;Firewall delle opzioni di mIRC
2) Disattivare la casella Server e attivare la casella DCC
3) Selezionare il protocollo SOCKS5
4) Inserire l'indirizzo IP del SOCKS interno alla MAN di Fastweb: 10.31.254.64
5) Inserire 1080 come porta, lasciare vuoti i campi User ID e Password
6) Clickare su OK
7) Proseguire dal punto 2 del caso successivo

CASO 2: DCC tra abbonati Fastweb

1) Andare alla sezione Connect-&gt;Firewall delle opzioni di mIRC e disabilitare la casella DCC se attivata
2) Andare alla sezione Connect-&gt;Local Info delle opzioni di mIRC
3) Inserire nella casella di testo IP Address il proprio IP privato
4) Disattivare la casella Local Host lasciando attiva la casella IP Address
5) Attivare la casella Normal sotto Lookup Method
6) Clickare su OK

NB: in entrambi i casi le istruzioni riportate si riferiscono alla versione 6.0 (o successive) di mIRC.

ATTENZIONE: a causa di una implementazione particolare delle DCC su mIRC nel primo caso le DCC funzioneranno solo verso altri utenti che usino mIRC e non usino SOCKS/Firewall
In caso di problemi il canale #irchelp è sempre a vostra disposizione.

NB: la versione aggiornata dell'alias /fwdcc è riportata nel post seguente.

Modifico il post per risolvere un problema riscontrato dagli utilizzatori del server delta.azzurra.org quando tentano di inviare DCC agli abbonati di altri provider. Tale soluzione si applica anche agli users che continuano ad utilizzare gli altri server di Azzurra.

Rispondo a me stesso per aggiungere un piccolo alias fatto ad hoc per automatizzare le operazioni sopra descritte.

Aprite la finestra Alias di mIRC (Alt+A) e copiate nella finestra il testo seguente:

Codice:
/fwdcc {
  if ($$1 == on) {
    localinfo -h
    .firewall -d off
    echo -at 2* Ora puoi usare le DCC verso abbonati Fastweb
  }
  if ($$1 == off) {
    localinfo -h
    .firewall -cm5+d on 10.31.254.64 1080
    .firewall +d off
    echo -at 2* Ora puoi usare le DCC verso abbonati di altri provider
  }
}

Chiudete il mIRC Editor clickando su OK.

Da questo momento potrete passare velocemente tra i due modi di utilizzo delle DCC:

Per inviare DCC ad abbonati Fastweb: /fwdcc on
Per inviare DCC ad abbonati di altri provider: /fwdcc off

Spero che questo alias possa esservi utile.

Come sempre #irchelp per dubbi vari.
