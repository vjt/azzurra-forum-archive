Modalità di compilazione diverse. In pratica l'attivazione o meno di alcune features che possono variare da server a server in modo da ottimizzare il singolo nel migliore dei modi.

Per quanto riguarda le versioni differenti, semplicemente per alcuni server non sono necessarie le modifiche apportate nell'ultima versione del nostro bahamut. Idem per il supporto SSL o IPv6
