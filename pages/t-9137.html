Lasciando a voi la soluzione matematica del problema, colgo l'occasione per affiancare la programmazione al calcolo scientifico. Il codice esposto qui sotto è una macro che calcola Velocità, Spazio perscorso e Accelerazione di un corpo sferico in un mezzo viscoso.

Sub Calcola()
'
' Calcola Macro
'
Dim g As Currency
Dim V0 As Currency
Dim massa As Currency
Dim Rsfera As Currency
Dim viscosità As Currency
Dim delta_t As Currency
Dim cost_attrito As Currency
Dim tempo As Currency
Dim posizione As Currency
Dim velocità As Currency
Dim accelerazione As Currency
Dim pi_greco As Currency
Dim differenza As Currency
Dim velocità_precedente As Currency

pi_greco = Range("$h$7").Value
g = Range("$b$7").Value
V0 = Range("$b$8").Value
massa = Range("$B$9").Value
Rsfera = Range("$b$10").Value
viscosità = Range("$b$11").Value
delta_t = Range("$b$12").Value
cost_attrito = 6 * pi_greco * viscosità * Rsfera / massa
vel_regime = g / cost_attrito
epsilon = Range("$e$7").Value
densità = Range("$e$10").Value
'vengono calcolati i valori iniziali e posti nella riga 14
tempo = 0
posizione = 0
velocità = V0
accelerazione = g
differenza = 10

'assegna alle celle della riga 14 i valori assegnati
Range("a14").Value = tempo
Range("b14").Value = velocità
Range("c14").Value = g * (1 - 4 / 3 * pi_greca * Rsfera ^ 3 * densità) - cost_attrito * V0
Range("d14").Value = posizione
Range("a14").Select
'viene calcolata la riga successiva e,se è valida la condizione,il procedimento prosegue.
'in pratica è un ciclo in cui la condizione è verificata all'inizio,cioè se la differenza
'tra la velocità raggiunta e quella dell'intervallo di tempo precedente è minore di
'epsilon(costante arbitraria piccola a piacere inserita nelle condizioni iniziali),
'allora scende di una riga ed esegue i calcoli, altrimenti si ferma.
Do While differenza > epsilon
tempo = tempo + delta_t
posizione = posizione + velocità * delta_t
velocità_precedente = velocità
velocità = velocità + accelerazione * delta_t
accelerazione = g * (1 - 4 / 3 * pi_greca * Rsfera ^ 3 * densità) - cost_attrito * velocità

'assegna alle celle i valori calcolati
ActiveCell.Offset(1, 0).Activate ' va giù di una riga
ActiveCell.Value = tempo
ActiveCell.Offset(0, 1).Activate 'va destra di una cella
ActiveCell.Value = velocità
ActiveCell.Offset(0, 1).Activate 'va adestra di una colonna
ActiveCell.Value = accelerazione
ActiveCell.Offset(0, 1).Activate 'va a destra di una colonna
ActiveCell.Value = posizione
ActiveCell.Offset(0, -3).Activate 'si poneall'inizio della riga
differenza = Abs(velocità - velocità_precedente)
Loop
Range("A14").Select


'
End Sub

Chi vuole può svolgere questo problema implementando il codice in un foglio Excel e ricavando i risultati controllarne la correttezza.
