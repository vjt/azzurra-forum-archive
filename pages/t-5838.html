Cercando un po' nell'help, si trova:

/scid &lt;-rsatM | N&gt; [command]
Changes the active connection for a script to connection id N, where N is a $cid value.
The /scon command works in exactly the same way, except that N represents the Nth connection, not a connection id value.

Questi due comandi (di cui non mi è ancora molto chiara la differenza) fanno si che si possa scegliere in quale connessione mandare il comando.
Esempio:
/scid 2 ame va

Questo comando fa un /ame in tutti i canale del secondo server cui si è connessi.
Per mandare un comando in tutti i server contemporanemanete, si può usare il flag -a, perciò, nel tuo caso diventa:

/scid -a quit messaggio

Spero di esserti stato utile :)
