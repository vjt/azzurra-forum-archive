Proprio di recente Sun ha finalmente vinto la causa contro Microsoft per la presenza della famigerata MS java virtual machine. Inopportuna, dato che java è proprietà di Sun.

Per questo motivo Microsoft cesserà di sviluppare Ms JVM (che tra l'altro ogni tanto necessitava di ingombranti patches per bachi di sicurezza) e questa non sarà più disponibile da windows update e nelle versioni future dei sistemi operativi.
Sun resta unica e legittima sviluppatrice di java virtual machine.

Puoi avere entrambe le virtual machines installate su Windows, e poi disattivare/attivare una in particolare da Internet Explorer -&gt; strumenti -&gt; opzioni internet -&gt; avanzate.
