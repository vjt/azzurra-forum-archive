Il mese scorso è uscito Familar 0.8, distribuzione Linux per palmari iPAQ&Co etc etc etc....

http://www.handhelds.org/geeklog/index.php


Changes since the prereleases:
* suspend problem with h5xxx wlan has been fixed
* autoloading of sound modules has been fixed
* bluez-utils-dbus now actually uses dbus
* ppp-dialin installs the right users and groups
* autoloading of mmc modules has been fixed
* sa1110_rtc modules are autoloaded, fixing time related bugs
* alignment checking is less strict, so bad apps (rxvt, sdl) don't crash

Bugs still present:
* ide_cs is still broken, this can be solved by installing an older version of ide_cs.
* when setting the wrong linuxargs opie refuses to boot
* SD card detection isn't working 100%
* the 'bl' command isn't present
* gpe user need to do chmod a+w /dev/sound/* to use sound as a non-root user
