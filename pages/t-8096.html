in pratica non c'è soluzione di connettersi ad azzurra con sygate?

Partendo dal presupposto che se non ricordo male sygate accetta solo ip.
La soluzione potrebbe essere usare un server specifico e non il roundrobin irc.azzurra.org. Vado a fare un esempio:

1) recuperi facendo un dns ip del server al quale ti vuoi connettere, supponiamo 2night.azzurra.org, (195.78.193.35) e del proxy-checker (213.203.143.50), proxy-check.azzurra.org

2) inserisci i due ip tra gli allowed di sygate

3) ti connetti con il tuo client irc a 2night.azzurra.org (con mirc /server 2night.azzurra.org)

Con questo procedimento non dovresti aver problemi :)

PS: il procedimento sopra vale per qualsiasi server di Azzurra IRC Network, chiaramente cambia l'ip del server quello del proxy-checker dovrebbe rimanere lo stesso.

qualora utilizzassi la versione Pro di Sygate Personal Firewall puoi disattivare l'active Response, cioè il blocco degli IP quando avvengono scansioni di porte come quella che effettua il proxy checker.

Trovi l'opzione in questione andando alla voce
Tools
Options
Security
Automatically block attackers IP addresses for [xxx] second(s)

Nell'edizione gratuita del firewall tale scelta è disattivata e bloccata
