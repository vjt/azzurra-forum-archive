In alcuni canali c'e' una certa filosofia tesa a scoraggiare l'uso massiccio di /ame ed /amsg , mentre gli utenti vorrebbero invece usarli per determinati script come ad esempio quelli di ascolto musica.
Che voi sappiate, /ame ed /amsg sono ridefinibili su mIRC con alias che permettano l'invio del messaggio ad esclusione di canali specifici e configurabili? Come si potrebbero fare questi alias?

Questi sono gli alias da mettere su mIRC per escludere il #NomeCanale dagli /ame ed /amsg :

amsg {
var %i = $chan(0)
while (%i > 0) {
if ($chan(%i) != #NomeCanale) msg $chan(%i) $1-
dec %i
}
}

ame {
var %i = $chan(0)
while (%i > 0) {
if ($chan(%i) != #NomeCanale) describe $chan(%i) $1-
dec %i
}
}

Se ci sono piu' canali da escludere, bisogna adattare la variabile in questo modo:

if ($chan(%i) != #NomeCanale1 && $chan(%i) != #NomeCanale2)

...e il resto rimane uguale.
