Per quanto non direttamente attinente con IRC, visto che molta gente usa la java virtual machine di Sun per far funzionare le applets, ritengo utile informare di questo problemino.

Se si possiede una scheda video ATI può capitare, alla chiusura di una qualsiasi applet java, di ritrovarsi il pc crashato con un BSOD (blue screen of death, la famosa schermata d'errore irreversibile di windows).

Il problema è stato risolto di recente da Sun con una nuova versione di java virtual machine, 1.4.1_02, che è possibile scaricare da questo link:
http://java.sun.com/j2se/1.4.1/download.html
