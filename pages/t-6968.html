Due to abuse on massive proxy, drones and spambot connections the access has been restricted on some servers of Azzurra IRC Network.

This is applied to these IRC servers: irc.eu.azzurra.org - irc.us.azzurra.org - irc.as.azzurra.org - irc.af.azzurra.org

The restriction is applied to all the following IRC commands: USERS - LIST - LINKS - ADMIN - JOIN - PRIVMSG - MSG - NOTICE

Appropriate exceptions are applied to all the IRC commands issued to services.azzurra.org , in order to allow the communication to the IRC Services, and to all the JOIN commands directed to the channel #OPERHelp , where you can ask for help about this subject.

Full access to all IRC services is granted to all the user connections that have been identified to a registered nickname (receiving therefore the usermode +r) by using the identification command /msg NickServ IDENTIFY nickname password (please use your own
nickname and password).

If you don't have a registered nickname on Azzurra, you can register the nickname you are using by typing this command: /msg NickServ REGISTER password e-mail (NOTE: you can use any password of your choice, between 5 and 32 characters); after that, an e-mail will be sent to the e-mail address specified, containing a 10-digits code that will be used to authenticate the nickname registration. The command will be specified in the email and will have this syntax: /msg NickServ AUTH 0000000000 (put your own code instead of the zeros). Please remind that the usermode +r will be assigned only after the authentication procedure, and the nickname registration will be deleted after 24 hours if there is no authentication.

A New chanmode (+U) has been introduced with this Network Upgrade. ChanMode +U enables all user to /JOIN your Channel without the NickName identification.

Should you have problems about this subject, you can join the channel #OPERHelp and ask there for help.

Versione Italiana

A causa di abusi dovuti all'utilizzo massivo di connessioni proxy, droni e spambot da parte di indirizzi IP stranieri, l'accesso per gli utenti non Italiani e' stato ristretto su alcuni server di Azzurra IRC Network. Questo e' valido per i seguenti IRC server: irc.eu.azzurra.org - irc.us.azzurra.org - irc.as.azzurra.org - irc.af.azzurra.org.

La restrizione si applica a tutti i seguenti comandi IRC: USERS - LIST - LINKS - ADMIN - JOIN - PRIVMSG - MSG - NOTICE
Eccezioni specifiche sono garantite per tutti i comandi IRC diretti a services.azzurra.org , in modo da consentire la comunicazione con i Servizi IRC, ed a tutti i comandi di JOIN riferiti al canale #OPERHelp , dove e' possibile chiedere informazioni a riguardo.

Pieno accesso a tutti i servizi IRC e' garantito a tutte le connessioni che sono state identificate ad un nickname registrato (ricevendo quindi lo usermode +r) tramite l'utilizzo del comando di identificazione /msg NickServ IDENTIFY nickname password (si prega di utilizzare il proprio nickname e la propria password).

Se non siete in possesso di un nickname registrato su Azzurra, potete registrare il nickname che state utilizzando digitando questo comando:: /msg NickServ REGISTER password e-mail (NB: si puo' usare qualsiasi password contenente tra 5 e 32 caratteri); successivamente, un e-mail verra spedita all'indirizzo e-mail specificato, contenente un codice che verra' usato per autenticare la registrazione del nickname. Il comando verra' specificato nell'email ed avra' questa sintassi: /msg NickServ AUTH 0000000000 (inserire il proprio codice al posto degli zeri).
Si prega di ricordare che lo usermode +r verra' assegnato solo dopo la procedura di autenticazione, e che la registrazione del nickname verra' cancellata dopo 24 ore se non e' seguita dall'autenticazione.

Qualora ci fossero problemi riguardo questo argomento, e' possibile entrare nel canale #OPERHelp e chiedere assistenza.
