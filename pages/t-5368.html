Come gli assidui frequentatori di IRC Junkie (http://www.irc-junkie.org) avranno gia' saputo, i ragazzi di mircscripts.org (http://www.mircscripts.org) hanno trovato un bug nel famoso script per mIRC Peace &amp; Protection che permette a chiunque di fare eseguire qualsiasi comando (fra cui ad esempio farsi inviare la password di nick/canali o formattare l'hard disk) sotto determinate condizioni.
Per correggere il problema e' sufficiente scaricare il file alias1.mrc (http://www.azzurra.org/alias1.mrc) e sostituirlo a quello originale nella directory C:\mIRC\script, oppure riscaricare l'intero script gia' aggiornato da mircscripts.org (http://www.mircscripts.org/comments.php?cid=1301).
