da ieri è linkato in test in via sperimentale il server delta.azzurra.org (213.140.23.227) situato all'interno della MAN Fastweb, questo server permette agli utenti Fastweb di entrare su Azzurra con il loro IP interno anzichè l'ip NAT *.fastres.net.
L'IP sara' naturalmente criptato, e in questo modo si e' al sicuro da possibili provvedimenti presi contro un NAT intero a causa di singoli elementi disturbatori. Inoltre l'identd funziona correttamente.
Non e' consentito connettersi con il socks a questo server; basta comunque impostarlo solo per le DCC e connettersi al server con il socks disattivo per entrare senza problemi.
Invitiamo tutti gli utenti con connettività Fastweb a provare il server e segnalarci eventuali problemi all'indirizzo email bugs@azzurra.org o sul canale #services. Vi ricordo che questo server è sperimentale, la continuità del servizio non è per il momento garantita.

Per le connessioni al server è attivo anche l'indirizzo fastweb.azzurra.org
