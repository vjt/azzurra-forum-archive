E' da oggi disponibile un nuovo server dedicato agli abbonati Fastweb. Il suo nome è omicron.azzurra.org ed è un server aziendale su IP pubblico.

Tale server dovrebbe contribuire a migliorare la qualità del servizio fornito agli abbonati Fastweb, portando a 3 il numero di server interni (delta.azzurra.org è temporaneamente fuori rete per motivi tecnici ma il rientro è previsto in tempi brevi).

Come gli altri, anche il nuovo server è accessibile anche dal round robin fastweb.azzurra.org, percui consigliamo vivamente l'utilizzo di tale indirizzo al fine di distribuire meglio il carico sui server disponibili.

Lo staff di Azzurra ringrazia WMG Italia (http://www.wmgitalia.it) per aver messo a disposizione il server e la connettività necessaria.
