Questa funzione, scritta così

for ($i = 0; $i < count($files); $i++) {

echo "<a href="$dir.$files[$i]"></a>";
}


non rende alcun output.
I doppi apici (") interni non sono escapati, inoltre un href senza oggetto linkato (come in questo caso) non viene visualizzato.

La sintassi corretta è:

for ($i = 0; $i < count($files); $i++) {
echo "<a href="$dir.$files[$i]">$files[$i]</a>";
}
