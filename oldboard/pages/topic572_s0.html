 Linux Cafè, Vicenza.

vi copio l'iniziativa:

http://www.vicenza.linux.it/linuxcafe/
-------------------------
Questa è la pagina ufficiale di Linux Cafè, gli incontri organizzati dal Linux User Group di Vicenza.


Che cosa è Linux Cafè?
Sono cinque serate in cui verrà presentato Linux a tutti gli interessati. Non è necessario essere già esperti di Linux per partecipare perchè gli incontri costituiscono un ottimo percorso introduttivo per tutti quelli che vogliono partecipare. Per coloro che ancora non conoscono Linux sarà una ottima occasione per iniziare, mentre per tutti quelli che già hanno esperienza sarà una ottima occasione per ripassare e imparare qualcosa di nuovo.

Quali sono le date?
Le date dei cinque incontri sono:
12 Marzo
26 Marzo
9 Aprile
23 Aprile
8 Maggio
E' possibile che le date possano cambiare a causa di impegni degli oratori. Sei quindi pregato di controllare su questo sito che gli incontri avvengano nelle date previste o di leggere gli avvisi di eventuali posticipi delle serate. Questo sito verrà sempre aggiornato per fornire tutte le informazioni necessarie alla partecipazione per tutti gli interessati.


Dove si svolge e a che ora?
Gli incontri si svolgeranno al Victoria Station in mure porta Santa Lucia. Gli incontri previsti hanno una durata dalle 21.00 alle 23.00 .

Che distribuzione userete?
Le distribuzione usata è Debian GNU/Linux aggiornata a woody.

Cosa mi devo portare se voglio partecipare?
Beh, dipende da cosa vuoi fare... Se il tuo interesse è solo quello di ascoltare allora puoi venire tranquillamente senza preoccuparti di nulla, se invece vuoi installare linux sul tuo computer allora dovrai portarti via il pc. Noi provvederemo ad organizzare un ambiente adatto all'installazione e all'uso di linux. Per sapere come devi preparare il tuo computer prima leggi le note.
Inoltre se decidi di installare linux sul tuo computer sei pregato di prenotare il tuo set di cd. Noi porteremo via di sicuro dei set di cd, ma ci dispiacerebbe non poterli fornire a tutti. In questo modo sarai sicuro che il tuo set di cd ti aspetta già pronto e sicuro. Ovviamente, anche sei ha già debian installata e vuoi un set di cd per aggiornare il tuo sistema puoi sempre prenotare le tue copie.


Qual'è il programma delle serate?
Nella prima serata verrà spiegato cosa è il software libero e verrà installato il sistema operativo Debian GNU/Linux sui computer degli interessati.
Nella seconda serata verrà configurato il sistema linux installato la volta precedente per potersi connettere, navigare, utilizzare applicativi office e masterizzare.

La terza serata sarà dedicata invece all'integrazione di computer linux e computer windows nella stessa rete.

La quarta serata sarà dedicata all'esplorazione delle risorse disponibili sul web per linux.

Per finire l'ultima serata sarà un po' più tosta, dedicata all'hacking su Linux e Hurd.


E se mi perdo una serata?
Peccato! Però non preoccuparti: dopo ogni serata aggiorneremo il sito web mettendo on-line i file delle presentazioni e tutta la documentazione presentata. Un motivo in più per tornare a visitare questa pagina!

Qualcosina in più?
Vista l'esperienza delle serate precedenti che abbiamo organizzato pensiamo di organizzare anche una piccola rete cui potranno accedere tutti coloro i quali saranno muniti di scheda di rete. In questo modo sarà possibile aggiornare i computer direttamente da un fileserver in lan senza dover passare per i cd. Chi vuole attaccarsi alla lan è pregato di portarsi via i cavi necessari.
